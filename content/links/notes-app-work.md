## Requirements

- A central location where I can see active projects and upcoming tasks.
- A page per project that acts as a repository for notes.
- A collection of meeting notes with transcriptions.
- An easy way to link between notes, with back-linking.
- An easy way to create a new note page (meeting transcript, artifact, etc.) with appropriate linking happening automatically.
- A view of all active tasks with deadline information visible.

## Maybe nice to have?

- Some way to see information chronologically. One straightforward way would be to have daily notes that just link to any new notes I made.

## Possible solutions

### Notion

It's easy to set up meeting notes, page per project, and various db views. The only think that's not clear is the linking back and forth. I don't want to do it manually, and setting up nested databases with buttons to click that auto-fill information is pretty clunky.

### Obsidian

Back-linking works easily, daily notes have plugin support, and actually I could probably do almost anything I want using plugins. The only problem here is that I'm not too happy with Obsidian's UI. It's fine for composing text files, but clicking around feels unintuitive and miss-clicking things has odd behavior, like creating new notes that I don't want.

### Noteplan

Appealing but expensive.
